# 主聊天公开回合设计

更新时间：`2026-03-23`

## 布局顺序
- 地区上下文
- 公开回合状态条
- 遭遇目标提醒条
- 当前轮输出
- 当前需要的内联输入面板
- 底部聊天框

## 输入原则
- 普通公开回合输入不再使用底部主聊天框。
- 主聊天叙述区内联承担：
  - 开始下一回合
  - 优先行动
  - 玩家本轮动作/台词输入
  - 互动回应
  - 攻击回应
  - 对抗规划
  - 等待信息检定提示
- 底部主聊天框只保留 God Mode 入口。

## 骰点原则
- 所有骰点仍保持弹窗：
  - 行动检定
  - 反应检定
  - 死亡豁免
  - 攻击防御
  - 对抗掷骰
  - 信息检定

## 遭遇展示原则
- 主列固定显示当前 active encounter 的 `goal`。
- 侧栏默认折叠，让主聊天更宽。
- 侧栏和遭遇弹窗都只显示 `goal + scene_summary + situation_value/trend`。

## 当前实现口径
- 公开回合结束后会刷新遭遇 `scene_summary`。
- 遭遇不再做后台自动推进。
- escape / rejoin 不再是现行玩法。
