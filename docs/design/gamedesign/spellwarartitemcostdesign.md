# 法术武技道具消耗设计

- 为法术武技道具设计使用规则


## 武技合法术消耗设计

- 设计一：费用制

  - 法术：

    - 法术施放需要消耗法术位，当前玩家只有法术值，这是之前设计遗留参数，删除以后用法术位代替
    - 法术位不完全采用DND规则，因为打算做长修短修，法术值采用回合恢复。
    - 所以玩家新增参数，法术位，当前法术位都是int，然后就是法术位恢复速度，多少法术位/每公开回合，默认为1法术位/回合
  - 武技点：

    - 类似于法术位，但获取方式不一样，法术位是常驻或者每回合恢复
    - 而武技点是靠战斗获取，玩家击中目标，受伤或者一些特殊武技本身就可以获取
    - 玩家新增武技位，当前武技位，默认为每击中一次/回合
  - 如何获取新的点：

    玩家升级获取，升级系统待设计，先留空，最高为9点。


- 设计二：冷却制
  - 武技合法术使用后有冷却时间，回合计数，法术环数直接转为冷却回合数即可


## 道具消耗设计

- 道具需要分类
  - 剧情关键道具，消耗品，杂物
  - 剧情关键道具：用于让剧情节点检测是否拥有以进入下一环节，先占位相关设计还未跟进
  - 消耗品：法术卷轴，炸弹，飞刀等会对世界空间造成影响的物品，使用后就消失的道具
  - 杂物：一些不会对世界空间造成影响的物品，但可以有一些其他作用。
